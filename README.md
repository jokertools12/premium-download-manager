# Premium Download Manager ⚡

مدير تحميل لسطح المكتب مثل Internet Download Manager لكن أسرع وأنيق ومجاني بالكامل.

## المميزات
- 🚀 تسريع حقيقي: تقسيم كل ملف حتى 32 اتصالاً متوازياً (Range Requests)
- ⏸ استئناف كامل حتى بعد إغلاق البرنامج أو انقطاع النت
- 🎬 **تحميل فيديوهات من آلاف المواقع** (YouTube, Twitter, TikTok...) عبر تكامل yt-dlp
- 📺 **دعم بثوث HLS/M3U8** مع اكتشاف تلقائي للروابط
- 🔧 دمج تلقائي لأعلى جودة عبر ffmpeg (تنزيل تلقائي عند الحاجة)
- 🌐 تكامل مع Chrome / Edge / Firefox عبر إضافة رسمية
- 🪟 نافذة عائمة مصغرة (تلقائية أو بزر 📌)
- 📐 قواعد تلقائية لتوجيه الروابط إلى مجلدات حسب كلمات مفتاحية
- 📄 استيراد جماعي للروابط (لصق أو ملف نصي)
- 📊 لوحة إحصائيات + رسم بياني حي للسرعة
- ⚡ تحديد السرعة القصوى + أولويات الطابور + تحميل فوري
- 🗂️ تصنيف تلقائي (فيديو، صوت، صور، مستندات، برامج...)
- ⏱️ جدولة زمنية + طوابير + عدد تحميلات متزامن قابل للضبط
- 📋 مراقبة الحافظة + سحب وإفلات الروابط
- 🌙 واجهة عربية أنيقة (داكن/فاتح) + شريط مهام Tray
- 🌍 **تعدد اللغات**: العربية / English / Türkçe مع تبديل الاتجاه RTL/LTR
- 🧲 **دعم التورنت والماجنط** عبر WebTorrent (فحص الماغنت + اختيار الملفات + عدد المصادر)
- 🔗 **مصادر بديلة Mirrors**: انتقال تلقائي للرابط البديل عند فشل الأساسي مع متابعة من نفس النقطة
- 💾 تخزين SQLite (مع تراجع تلقائي لـ JSON) + ترحيل تلقائي للبيانات القديمة

## التشغيل (وضع التطوير)
```
npm install
npm start
```

## تكامل المتصفح
1. شغّل البرنامج
2. شغّل `src\extension\install.bat` (يسجّل Native Host للمتصفحات)
3. افتح `chrome://extensions` → فعّل "وضع المطور" → "تحميل إضافة غير مضغوطة" → اختر مجلد `src\extension`

## بناء نسخة التثبيت (Setup.exe)
```
npm run dist
```
الملف الناتج في مجلد `dist`.

## البنية
```
src/
  main/          نواة Electron (محرك التحميل، الطوابير، التكاملات)
  preload.js     جسر آمن بين النواة والواجهة
  renderer/      الواجهة (HTML/CSS/JS)
  extension/     إضافة المتصفح + أدوات تثبيت Native Messaging
```
