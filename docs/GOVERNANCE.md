# 🏛️ ميثاق الحوكمة المفتوحة والمعايير الهندسية (المرحلة 12.4)
## Premium Download Manager

> **العهد الأساسي**: Premium Download Manager مشروع مجاني 100%، مفتوح المصدر بالكامل (ترخيص MIT)، بلا إعلانات، بلا تتبع خبيث، وبلا نسخة Pro مدفوعة للأبد.

---

## 1. دورة الإصدارات و SemVer

نلتزم الصرامة بمبادئ **Semantic Versioning 2.0.0** (`MAJOR.MINOR.PATCH`):
- **MAJOR (v3.0.0)**: تغييرات معمارية كبرى أو كسر في توافق واجهات البرمجة العامة (مع توفير محولات توافق مؤقتة).
- **MINOR (v2.1.0, v2.2.0, ...)**: إضافة ميزات جديدة متوافقة عكسياً دون كسر أي وظائف سابقة.
- **PATCH (v2.1.1, ...)**: ترقيعات أمنية وإصلاحات أعطال سريعة.

دورة الإصدارات المعتمدة: **كل 6 أسابيع** لإصدارات Minor، مع ترقيعات Patch فورية عند اكتشاف أي ثغرة.

---

## 2. مصفوفة الأمان والجودة الإلزامية قبل أي دمج (PR Checklist)

كل طلب دمج (Pull Request) يجب أن يستوفي الشروط التالية آلياً:
1. **الاختبارات الآلية**: نجاح 100% لكافة الاختبارات الوحدوية واختبارات الحمل (`npm test`).
2. **التدقيق الأمني**: اجتياز فحص `node scripts/security-audit.js` بدون أي تحذيرات حرجة.
3. **التوافق اللغوي**: تطابق المفاتيح في كافة اللغات الثمانية المدعومة في `src/renderer/i18n.js`.
4. **Offline-First**: أي قدرة ذكاء اصطناعي مضافة يجب أن تعمل محلياً تماماً دون اشتراط الاتصال بالإنترنت.

---

## 3. المجتمع والمساهمة

- **النقاشات والأولويات**: تجري على GitHub Discussions للتصويت على الميزات القادمة بشفافية.
- **نظام الترجمة**: ترجمة مجتمعية مستمرة عبر Weblate و GitHub.
- **التبرعات والدعم**: عبر GitHub Sponsors بشفافية تامة لتغطية تكاليف البنية التحتية فقط (توقيع الشهادات وخوادم CI)، مع بقاء البرنامج مجانياً ومفتوحاً للجميع.
